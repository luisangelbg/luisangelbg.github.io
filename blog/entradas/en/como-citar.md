If you used one of the applications of the suite in your thesis, paper or report, cite it like any other source. That way other researchers can reproduce your analysis.

## Use the Zenodo DOI

The published applications have a **concept DOI** in Zenodo. That DOI always points to the most recent version. Each version also has its own DOI, which is worth using when you need to state exactly which version you worked with.

The citation takes this form:

> Barrera-Guzmán, L. Á. (2026). *PCAPro: an offline, browser-based platform for guided principal component analysis* (Version 1.1.0) [Software]. Zenodo. https://doi.org/10.5281/zenodo.22649709

## Where to find the ready-made citation

- On the **page of each application** on this site there is a *Copy citation* button.
- Inside each application, on its home screen, there is a **How to cite** link.
- In the code repository, the `CITATION.cff` file lets you copy the citation in APA or BibTeX format with the button for citing the repository.

## In the methods section

Besides the citation, mention the version and the settings you used. Many applications produce a report with the methods text already written with your own parameters; you can adapt it to your style.
