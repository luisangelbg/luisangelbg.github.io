Cómo usar las descargas

Usar sin conexión

Descarga el .zip, descomprímelo y abre index.html con doble clic. Si la app trae datos de ejemplo, usa el archivo Open …bat o server.ps1 para cargarlos.

Datos de ejemplo

Cada aplicación incluye conjuntos de datos reales o simulados para practicar. Están dentro del .zip, en la carpeta data o datos, y se cargan con un botón desde la propia app.

Versiones anteriores

Cada versión publicada queda archivada en Zenodo con su propio DOI. Desde la ficha de cada app puedes llegar a su registro.
